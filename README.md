# Shanti Yoga

Bem-vindo ao projeto **Shanti Yoga**! Este é um site institucional dedicado a promover o bem-estar e a prática de yoga, oferecendo informações sobre aulas, filosofia e benefícios da prática.

## Sobre o Projeto

O Shanti Yoga é um site criado com o objetivo de apresentar informações sobre a prática do yoga. Com uma identidade visual suave e relaxante. Este projeto é desenvolvido com foco em uma interface agradável, amigável e responsiva.


## Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo
- **CSS3**: Estilização e design responsivo
- **Bootstrap 5**: Framework para layout e componentes responsivos
- **jQuery**: Efeitos de interação e manipulação do DOM
- **Owl Carousel**: Exibição de imagens e conteúdos de forma deslizante
- **AOS (Animate on Scroll)**: Efeitos de animação durante a rolagem
